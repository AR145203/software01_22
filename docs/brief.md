# 项目简报

## 成功定义
首个里程碑不是交付代码，而是回答：谁在什么场景遇到什么问题，为什么需要独立硬件，以及什么结果足以继续投入。

## 当前未知
- 目标用户及可招募渠道；是否能在一周内接触 5 人。
- 最近一次真实问题、发生频率、损失、现有替代方案。
- 桌面/随身场景、供电、网络、尺寸、反馈方式与可接受成本。
- 是否需要语音和 AI；离线能否完成主要任务。

## 首轮范围
临时场景：桌面工作者在忙碌时记录一条待办，并知道记录已成功。
用纸板按键、手机和人工处理模拟，不购买硬件；不承诺识别准确率或自动化能力。
不覆盖医疗、安全报警、自动控制电器等高风险用途。

## 约束
首轮最多 7 天，总投入建议不超过 8 小时；费用上限暂设 0 元，已有器材复用。
这些是实验边界，不是最终产品要求。负责人和实际开始日期在实验启动时填写。
